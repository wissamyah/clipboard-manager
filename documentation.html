Clipboard Manager

A fast, keyboard-friendly clipboard history for Chrome. Save text, find it again in a keystroke, and keep everything on your own device.

Version 2.3.0 Updated November 22, 2026

What's new in 2.0

New interface

Compact rows, one search bar and filter chips. Click any row to copy it.

Light and dark themes

Follows your system, or choose a theme in Settings.

Automatic saving

Optionally record everything you copy, in Chrome or any other app, without pressing Save.

Edit and name items

Change saved text, give it a name and build reusable snippets.

Side panel

Keep your history open beside the page you are working on.

Floating window

Open the list in its own small window that stays open while you work.

Shortcut and right-click

Open with Alt Shift V, or save a selection from the context menu.

New in version 2.3. Paste an item straight into the page with Ctrl / ⌘ Enter or the right-click menu. Ctrl / ⌘ 1–9 copies the item in that position, and automatic saving can be paused and now skips private keys and access tokens. Hovering a row turns its icon into a checkbox, so you can select several items and pin, favorite, delete or copy them as one. The footer has two new buttons on the right: one pauses automatic saving for 5 minutes, the other opens Settings.

New in version 2.2. Automatic saving now records text you copy anywhere on your computer, not only on web pages, and no longer needs access to the sites you visit. There is a new floating window, and the side panel and floating window each have a button next to Save. See About automatic saving for what this means for passwords you copy.

Deleting now offers Undo, search matches are highlighted, and backups export to a JSON file that can be imported again. If you used version 1.x, see Upgrading from 1.x.

Getting started

  1. Pin the extension. Click the puzzle-piece icon in Chrome's toolbar and pin Clipboard Manager.
  2. Open it. Click the icon or press Alt Shift V.
  3. Save something. Copy any text, then click Save.
  4. Use it again. Click a row to copy it back to your clipboard.

Saving text

There are four ways to add an item to your history.

MethodHow
Save buttonCopy text anywhere, open Clipboard Manager and click Save.
Right-clickSelect text on a page, right-click and choose Save selection to Clipboard Manager. The toolbar icon shows a check mark when it is saved.
Automatic savingTurn on Save copies automatically in Settings. Text you copy or cut anywhere on your computer is saved for you while Chrome is running.
New snippetOpen the ⋯ menu and choose New snippet to type an item by hand. New snippets are pinned.

Saving text you already have does not create a duplicate; the existing item moves to the top. A single item can hold up to 100,000 characters. Only text is supported, not images or files.

About automatic saving

  • It is off by default. Turn it on in Settings; no extra permission is needed.
  • It saves text copied anywhere: web pages, the address bar, PDFs and other apps. It works while Chrome is running, even in the background, and a copy appears within about a second.
  • Text that looks like a card number, a private key or an access token (GitHub, AWS, Stripe, JWT and similar) is skipped; you can turn that off in Settings. Passwords are not skipped: the clipboard does not say where a copy came from.
  • Pause it before copying something you do not want kept: open the ⋯ menu and choose Pause saving for 5 minutes or 1 hour, or click the pause button at the right of the footer to pause for 5 minutes. The footer shows when saving resumes; click it to resume sooner. Nothing copied during a pause is saved.
  • Copying an item from Clipboard Manager itself does not save it again. Whatever was on the clipboard before you turned it on is not saved.

Saved text is not encrypted. With automatic saving on, anything you copy is stored, including passwords and other things you may not want kept. Pause saving first, or delete those items afterwards, and consider turning on automatic deletion in Settings. Details are in the privacy policy.

Finding items

  • Search. Just start typing. Search looks at the text, the name and the tags of every item, and highlights the matches. Several words narrow the results.
  • Filters. Use the chips under the search bar: All, Pinned, Favorites, Links or Code. Tag chips can be combined with them and with each other.
  • Sort. The arrow at the end of the chip row switches between newest first and oldest first. Pinned items always stay on top.

Each item is labelled automatically as a link, email address, phone number, color, code or plain text.

Working with items

  • Copy. Click a row. The row confirms with a check mark.
  • Paste into the page. Click in a text field on the page, open Clipboard Manager, select the item with the arrow keys and press Ctrl / ⌘ Enter. The text goes straight into the field and your clipboard is left as it was. You can also right-click a text field and pick one of your pinned or recent items under Paste from Clipboard Manager. If no text field is selected, or Chrome does not allow access to the page, the item is copied instead so you can paste it yourself. Pasting is most reliable from the popup and the right-click menu; in the side panel and the floating window Chrome only allows it on a tab where you have already opened the popup.
  • Pin, favorite, delete. Hover a row, or select it with the arrow keys, to show its actions.
  • Details. Click the arrow on a row to see the full text, edit it, add a name, manage tags or open a link in a new tab.
  • Undo. Deleting shows an Undo button for a few seconds.
  • Select several. Hover a row and tick the checkbox that replaces its icon, or choose Select items from the ⋯ menu, to pin, favorite or delete many items at once, or to copy them as one text, one item per line.
  • Side panel. Click the side panel button next to Save to keep the list beside the page.
  • Floating window. Click the floating window button next to Save to open the list in its own small window that stays open while you work. It reopens where you last left it. Chrome cannot keep it above other windows.

Pinned items and favorites are protected. They are never removed by the item limit, automatic deletion or Clear history. To remove one, delete it directly.

Tags

  • Open an item's details, type in Add tag… and press Enter. Tags you already use are suggested.
  • Click the × on a tag to remove it.
  • Every tag appears as a filter chip above the list, and gets its own color automatically.
  • A tag disappears once no item uses it, so there is nothing to clean up.

Settings

Open the ⋯ menu and choose Settings, or click the gear at the right of the footer.

SettingWhat it does
ThemeSystem, Light or Dark.
Save copies automaticallySaves the text you copy anywhere on your computer while Chrome is running. Off by default. Pause it from the ⋯ menu or the pause button in the footer.
Skip card numbers and secret keysAutomatic saving leaves out text that looks like a card number, a private key or an access token. On by default. Passwords cannot be recognized.
Open shortcutShows the current shortcut and lets you change it.
Keep up to100, 500, 1,000 or 5,000 items. The oldest unprotected items are removed first.
Delete automaticallyNever, or after 7, 30 or 90 days. Off by default.
Relative timesShow “5m” instead of a clock time.
OverviewItem counts, a 7-day activity chart and the storage in use.
Clear historyRemoves everything except pinned items and favorites.

If a change to the limits would remove items, Clipboard Manager tells you how many and asks first.

Import and export

  • Export JSON. A complete backup with names, tags, pins and favorites. It can be imported again, on this or another computer.
  • Export text. A readable file with items separated by a ----- line.
  • Import. Accepts JSON backups and text files. Items you already have are skipped.

Exported files are ordinary, unencrypted files in your downloads folder. Store them somewhere you trust.

Chrome gives the extension 10 MB of storage. The Overview in Settings shows how much is in use.

Upgrading from 1.x

Your existing history, favorites, pins and tags are carried over automatically the first time version 2.0 runs. A few things work differently:

  • Statistics page. Replaced by the smaller Overview in Settings.
  • Optimize Storage. Removed. Use Keep up to and Delete automatically instead; both ask before removing anything.
  • Tag management. No longer needed, because unused tags disappear on their own.
  • Preview (eye icon). Replaced by the details panel, which also lets you edit.
  • Content types. Items are re-labelled with the improved detection, so some that were marked as code are now plain text.
  • Text export. No longer includes timestamps. Use JSON when you need a full backup.
  • Permissions. The update adds the right-click menu and the side panel. It does not ask for access to the sites you visit.

Troubleshooting

ProblemWhat to check
Save does nothingThe clipboard must contain text. Images and files are not supported.
A copy was not saved automaticallyCheck that Save copies automatically is on and that Chrome is running. Check that saving is not paused (the footer says so). Only text is saved, not images or files. Card numbers, private keys and access tokens are skipped unless you turned that off, and copying the same text twice in a row counts once.
Paste into the page copied insteadClick in the text field first, then open Clipboard Manager from the toolbar icon or the shortcut. Chrome does not allow extensions on its own pages or the Chrome Web Store, and some editors that draw their own text area do not accept inserted text.
The shortcut does not workAnother extension may already use it. Change it from Settings.
The file picker closes the popupOpen Clipboard Manager in the side panel or the floating window and import from there.
Items are disappearingCheck Keep up to and Delete automatically in Settings. Pin or favorite anything you want to keep.
