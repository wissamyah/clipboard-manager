Clipboard Manager

A fast, keyboard-friendly clipboard history for Chrome. Save text, find it again in a keystroke, and keep everything on your own device.

Version 2.0.0 Updated November 21, 2026

What's new in 2.0

New interface

Compact rows, one search bar and filter chips. Click any row to copy it.

Light and dark themes

Follows your system, or choose a theme in Settings.

Automatic saving

Optionally record what you copy on web pages, without pressing Save.

Edit and name items

Change saved text, give it a name and build reusable snippets.

Side panel

Keep your history open beside the page you are working on.

Shortcut and right-click

Open with Alt Shift V, or save a selection from the context menu.

Deleting now offers Undo, search matches are highlighted, and backups export to a JSON file that can be imported again. If you used version 1.x, see Upgrading from 1.x.

Getting started

  1. Pin the extension. Click the puzzle-piece icon in Chrome's toolbar and pin Clipboard Manager.
  2. Open it. Click the icon or press Alt Shift V.
  3. Save something. Copy any text, then click Save.
  4. Use it again. Click a row to copy it back to your clipboard.

Saving text

There are four ways to add an item to your history.

MethodHow
Save buttonCopy text anywhere, open Clipboard Manager and click Save.
Right-clickSelect text on a page, right-click and choose Save selection to Clipboard Manager. The toolbar icon shows a check mark when it is saved.
Automatic savingTurn on Save copies automatically in Settings. Everything you copy or cut on web pages is saved for you.
New snippetOpen the ⋯ menu and choose New snippet to type an item by hand. New snippets are pinned.

Saving text you already have does not create a duplicate; the existing item moves to the top. A single item can hold up to 100,000 characters. Only text is supported, not images or files.

About automatic saving

  • It is off by default. When you turn it on, Chrome asks you to allow access to the sites you visit.
  • Password fields, payment-card fields and text that looks like a card number are never saved.
  • It only sees copies made on web pages, not in other apps or on Chrome's own pages.
  • Turning it off also removes the site access.

Saved text is not encrypted. With automatic saving on, anything you copy on a page is stored, including things you may not want kept. Consider turning on automatic deletion in Settings. Details are in the privacy policy.

Finding items

  • Search. Just start typing. Search looks at the text, the name and the tags of every item, and highlights the matches. Several words narrow the results.
  • Filters. Use the chips under the search bar: All, Pinned, Favorites, Links or Code. Tag chips can be combined with them and with each other.
  • Sort. The arrow at the end of the chip row switches between newest first and oldest first. Pinned items always stay on top.

Each item is labelled automatically as a link, email address, phone number, color, code or plain text.

Working with items

  • Copy. Click a row. The row confirms with a check mark.
  • Pin, favorite, delete. Hover a row, or select it with the arrow keys, to show its actions.
  • Details. Click the arrow on a row to see the full text, edit it, add a name, manage tags or open a link in a new tab.
  • Undo. Deleting shows an Undo button for a few seconds.
  • Select several. Choose Select items from the ⋯ menu to pin, favorite or delete many items at once.
  • Side panel. Choose Open in side panel from the menu to keep the list beside the page.

Pinned items and favorites are protected. They are never removed by the item limit, automatic deletion or Clear history. To remove one, delete it directly.

Tags

  • Open an item's details, type in Add tag… and press Enter. Tags you already use are suggested.
  • Click the × on a tag to remove it.
  • Every tag appears as a filter chip above the list, and gets its own color automatically.
  • A tag disappears once no item uses it, so there is nothing to clean up.

Settings

Open the ⋯ menu and choose Settings.

SettingWhat it does
ThemeSystem, Light or Dark.
Save copies automaticallySaves what you copy on web pages. Off by default.
Open shortcutShows the current shortcut and lets you change it.
Keep up to100, 500, 1,000 or 5,000 items. The oldest unprotected items are removed first.
Delete automaticallyNever, or after 7, 30 or 90 days. Off by default.
Relative timesShow “5m” instead of a clock time.
OverviewItem counts, a 7-day activity chart and the storage in use.
Clear historyRemoves everything except pinned items and favorites.

If a change to the limits would remove items, Clipboard Manager tells you how many and asks first.

Import and export

  • Export JSON. A complete backup with names, tags, pins and favorites. It can be imported again, on this or another computer.
  • Export text. A readable file with items separated by a ----- line.
  • Import. Accepts JSON backups and text files. Items you already have are skipped.

Exported files are ordinary, unencrypted files in your downloads folder. Store them somewhere you trust.

Chrome gives the extension 10 MB of storage. The Overview in Settings shows how much is in use.

Upgrading from 1.x

Your existing history, favorites, pins and tags are carried over automatically the first time version 2.0 runs. A few things work differently:

  • Statistics page. Replaced by the smaller Overview in Settings.
  • Optimize Storage. Removed. Use Keep up to and Delete automatically instead; both ask before removing anything.
  • Tag management. No longer needed, because unused tags disappear on their own.
  • Preview (eye icon). Replaced by the details panel, which also lets you edit.
  • Content types. Items are re-labelled with the improved detection, so some that were marked as code are now plain text.
  • Text export. No longer includes timestamps. Use JSON when you need a full backup.
  • Permissions. The update adds the right-click menu and the side panel. Site access is only requested if you turn on automatic saving.

Troubleshooting

ProblemWhat to check
Save does nothingThe clipboard must contain text. Images and files are not supported.
A copy was not saved automaticallyAutomatic saving only works on web pages. It skips password and card fields, and cannot run on Chrome's own pages such as the Web Store.
The shortcut does not workAnother extension may already use it. Change it from Settings.
The file picker closes the popupOpen Clipboard Manager in the side panel and import from there.
Items are disappearingCheck Keep up to and Delete automatically in Settings. Pin or favorite anything you want to keep.
