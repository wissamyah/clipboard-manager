Privacy policy

Your clipboard stays on your device

This policy explains what Clipboard Manager stores, when it reads text, and the control you have over it.

Version 2.3.0 Last updated November 22, 2026 Effective November 22, 2026

The short version

Everything Clipboard Manager saves is kept in Chrome's local storage on your computer. The extension makes no network requests. We don't collect, transmit, sell or share your clipboard content or any other personal information, and there are no analytics, ads or accounts.

What changed in version 2.3

Version 2.3 adds a way to put saved text straight into a page, and more control over automatic saving. No new permission is requested.

  • Paste into the page. When you ask for it (Ctrl/⌘ Enter on an item, or right-click → Paste from Clipboard Manager), the extension inserts that item's text into the text field you are in. It looks for the focused field and writes the text there; it does not read the page's content. This uses the permissions the right-click “Save selection” item already had.
  • The right-click menu lists a few saved items. In a text field, the menu shows the start of up to ten items (pinned first, then the most recent) so you can pick one. Chrome keeps these labels on your device like the rest of your history.
  • Pause automatic saving. You can pause it for 5 minutes or 1 hour. While paused, the clipboard is not read at all.
  • More secrets are skipped. Besides payment-card numbers, automatic saving now leaves out text that looks like a private key or an access token. This can be turned off in Settings. Passwords still cannot be recognized.

What changed in version 2.2

Version 2.2 changed how automatic saving works, and with it what the extension can read.

  • Automatic saving now covers everything you copy. It used to save only text copied on web pages. It now reads the clipboard itself, so it also saves text you copy in other apps, in the address bar and in PDFs, for as long as Chrome is running. It is still optional and off by default.
  • Password fields are no longer recognized. The clipboard does not say where a copy came from, so a password you copy while automatic saving is on is saved like any other text. Text that looks like a payment-card number is still skipped.
  • Site access is gone. Automatic saving no longer runs a script on the pages you visit, so the extension no longer asks for access to the sites you visit. If you had granted it, the update removes it.
  • Floating window. The history can be opened in its own small window. It shows the same local data.

If you had automatic saving turned on before this update, it stays on and now works as described above. You can turn it off in Settings at any time.

What changed in version 2.0

Version 2.0 added features that affect when the extension can read text. All of them keep your data on your device.

  • Automatic saving (optional, off by default). Introduced in 2.0 for text copied on web pages; see above for how it works now.
  • Right-click “Save selection”. Saves the text you have selected on the current page when you choose that menu item.
  • Side panel. Shows the same history beside the page.
  • No more external requests. Earlier versions loaded a font from Google Fonts and website icons from a Google service, which exposed the domains of saved links. Both were removed. The extension now uses system fonts and built-in icons only.
  • Cleanup is now opt-in. The Optimize Storage feature, which removed items older than 90 days, is gone. Items are only removed automatically if you choose a limit or a time period in Settings.

The extension stores the following only on your local device, using Chrome's storage API.

The Overview in Settings (item counts and a 7-day activity chart) is calculated on your device from this data each time you open it. Nothing is logged or sent.

Automatic saving

Automatic saving is off by default. When you turn on Save copies automatically in Settings:

  • While Chrome is running, the extension checks the clipboard about once a second from a hidden page of its own.
  • When the text on the clipboard changes, the new text is saved to your local history. This covers anything you copy or cut on your computer, in Chrome (including Incognito windows) or in any other app, even while Chrome is in the background.
  • Text that looks like a payment-card number, a private key or an access token in a well-known format (for example GitHub, AWS, Stripe or a JSON Web Token) is skipped, unless you turn off Skip card numbers and secret keys. Nothing else is filtered: the clipboard does not reveal which app or field a copy came from, so passwords, one-time codes and other secrets without a recognizable shape are saved.
  • You can pause automatic saving for 5 minutes or 1 hour from the ⋯ menu, or for 5 minutes with the pause button in the footer. During a pause the hidden page is closed and the clipboard is not read; what you copy in that time is never saved, including after the pause ends.
  • Only text is read. Images and files are ignored. Whatever was on the clipboard before you turned the setting on, or before Chrome started, is not saved.
  • Automatic saving does not read or change the pages you visit, and it does not send anything anywhere.
  • Turning the setting off closes the hidden page and stops the clipboard checks immediately. Nothing is read when Chrome is not running.

Please note: with automatic saving on, sensitive text you copy, such as a password from a password manager or a one-time code, will be saved. Saved text is not encrypted. Pause automatic saving before you copy a secret, delete such items from your history, or leave automatic saving off if you copy secrets often.

Saving a selection from the right-click menu

When you choose Save selection to Clipboard Manager, the extension reads the selected text on that page at that moment and saves it. It does not read anything else on the page, and it works whether or not automatic saving is on.

Pasting a saved item into a page

When you press Ctrl/⌘ Enter on an item, or choose an item under Paste from Clipboard Manager in the right-click menu, the extension inserts that item's text into the text field that has focus on the current page. It checks which field is focused and writes the text there. It does not read what the page or the field contains, it does nothing on a page until you ask, and the page receives only the text you chose to paste.

What we don't do

  • No external servers. We don't operate or connect to any server.
  • No network requests. The extension does not contact any website or service.
  • No analytics or tracking. No usage data is gathered.
  • No data transmission. Your clipboard content never leaves your device.
  • No profiling. We don't build profiles or track behavior.
  • No ads.
  • No third-party access. Nobody else receives your data.
  • No cloud sync. Data is not synced between devices.

How your data is used

Your saved text is used only inside the extension, to:

  • Show your history in the popup and the side panel
  • Search and filter your items
  • Manage pins, favorites, names and tags
  • Copy an item back to your clipboard when you click it
  • Show the Overview in Settings
  • Create export files and read import files that you choose

Security

  • Chrome's storage. Data is kept in the extension's own storage area, which other websites and extensions cannot read.
  • Not encrypted. Saved text is stored as plain text in your Chrome profile. Anyone with access to your computer account could read it.
  • Safe display. Saved text is always shown as plain text and is never run as code or HTML.
  • Export files. Files you export are ordinary, unencrypted files. You decide where they are kept and who can see them.

Sensitive information: avoid saving passwords, API keys and similar secrets. If you use automatic saving, consider turning on Delete automatically in Settings so old items do not accumulate.

Your control

  • See it. Everything stored is visible in the extension.
  • Export it. Download your full history as JSON or text at any time.
  • Edit or delete it. Change or remove individual items, select several, or clear the history.
  • Uninstall. Removing the extension deletes all of its stored data.

Retention

  • Items are kept until you delete them, they exceed the item limit you chose (1,000 by default), or you uninstall the extension.
  • Automatic deletion is off by default. If you turn it on, items older than 7, 30 or 90 days are removed.
  • Pinned items and favorites are not removed by the item limit, automatic deletion or Clear history.
  • After you delete an item, an Undo option is available for a few seconds. Once it is gone the item cannot be recovered, and no backup is kept.

Third-party services

The extension uses no third-party services. Fonts are your system's own, icons are built in, and all code is bundled with the extension. No external requests are made and no remote code is loaded.

If you open a saved link, it opens in a normal Chrome tab and that website's own privacy policy applies.

Chrome Web Store User Data Policy

Clipboard Manager's use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Specifically:

  • Data is used only to provide the clipboard history features described here.
  • Data is not transferred to anyone.
  • Data is not used for advertising, for creditworthiness or lending purposes, or sold.
  • No human reads your data; it never leaves your device.

Children's privacy

Clipboard Manager is a general productivity tool not specifically directed at children under 13. We don't knowingly collect any information from children; the extension does not collect information from anyone.

GDPR

For users in the European Union:

  • Processing: we do not receive or process your data. It is handled only on your device, under your control.
  • Right to erasure: delete any or all data at any time in the extension.
  • Data portability: export your data with the Export feature.
  • No cross-border transfers: data never leaves your device.

Continued use of the extension after changes constitutes acceptance of the updated policy.
